# Malika — Frontend Developer Portfolio

## Как запустить
1. Распакуйте архив.
2. Откройте папку `malika-portfolio` в VS Code.
3. Откройте файл `index.html` в браузере (можно через расширение Live Server).

Проект сделан на HTML, CSS и JavaScript без установки дополнительных библиотек.

## Что можно изменить
- Тексты обо мне — в `index.html`.
- Цвета, размеры и адаптивность — в `style.css`.
- Поведение мобильного меню — в `script.js`.
